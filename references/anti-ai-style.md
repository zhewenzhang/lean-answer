# 去 AI 味：规则、改写与检查

目的：让文字读起来是人写的。**只改表达，不改事实、判断与结构。**

（这节被 SKILL.md 引用；规则、改写器、检查项三者一一对应，没有「靠感觉」的条目。）

## 标点黑名单（ERROR）

| 规则 | 错 | 对 |
|---|---|---|
| 中文正文用「」，不用英文双引号 | 学会"看见"自己 | 学会「看见」自己 |
| 数字与中文之间不加空格（4位年份可留） | 用了 3 个月 | 用了3个月 |
| 破折号全文 ≤1 处，禁止用它引出解释或升华 | 他走了——留下一个时代 | 他走了，项目停摆两个月 |
| 不给普通词加引号 | 学会「看见」自己 | 学会看见自己 |

## 句式黑名单（同篇 ≥2 次 ERROR，1 次 WARN）

| 句式 | 改法 |
|---|---|
| 不是A，而是B | B，而非A |
| 与其说A，不如说B | 只说B |
| 真正的X，从来不是Y | 只说Y（或「Y，而非X」） |
| 关键不在于A，而在于B | 关键在B |
| 这背后其实反映了 | 原因是（换成具体机制） |
| 这意味着我们需要重新审视 | 所以要改的是 |
| 值得注意的是／一个容易被忽略的问题是 | 删 |
| 越来越觉得／从被动接受到主动选择 | 删／开始主动选择 |
| 以前总觉得A，后来才明白 | 以前以为A，后来发现 |

## 不做的事

- **不替用户升华**。工作累就写累，不写「在不确定性中寻找内心的秩序」。
- **不用抽象词充数**：内在秩序、自我和解、精神内核、深层需求、底层逻辑、赋能、闭环、抓手、颗粒度 → 换具体指代（WARN）。
- **不编用户的感受与经历**。没有的事实标 [待补充]。脚本查不了，靠人守。

## 改写流程（三步，不跳）

1. 判原文属于交付物还是对话稿。交付物只改表达层，不动结构与判断。
2. 跑 `python scripts/deai.py 原稿.md`：出逐处改动表与改后全文。`--apply` 另存 `<名>.deai.md`，`--diff` 只列改动行。
3. 逐条处理输出里「需人工处理」的项，尤其句首删词（删了会破句）、破折号超量、抽象词。改完再跑一次，退出码 0 才交付。

**禁整篇重写**，除非用户明确要求。整篇重写会改掉原意，且看不出改了什么。

## 改写器的边界（实测）

| 能做 | 不能做 |
|---|---|
| 引号、数字空格、12 类包浆句式的定向替换 | 需要重写整句的（如句首「值得注意的是，」） |
| 剥代码块／行内代码／URL／表格行／引用块后判定 | 判断某个抽象词在此处是否真的空泛 |
| 繁简归一后同样命中 | 挑出「替用户升华」的句子 |

所以它只能减少 80% 的机械劳动，剩下 20% 必须人看。

## 与检查脚本的对应

```text
lint_style.py   只读检查：引号 / 空格 / 破折号 / 句式次数 / 抽象词
deai.py         读 + 改：出改动表与改后全文，改完自动调 lint_style 看残留
                （有硬违规退出码 1，可直接串进 CI 或 release）
```

脚本先剥离代码块、行内代码、URL、引用块与表格行再判定；繁体写法经繁简归一后同样命中。
