# 制图规范（内建 SVG 图表）

绘制内建 SVG 示意图时加载本文件。

- 画布固定 viewBox 宽 680，安全区 x 40–640；所有元素先算坐标再画。
- 同层节点等宽等高；每行最多 4 个，间距 ≥ 20px。
- 节点标题 ≤ 6 字、副标 ≤ 8 字；节点宽 ≥ 字数 × 7px + 24px。宁可换行或缩写，不可溢出或贴边。
- 发出前自检：最右元素 x + 宽 ≤ 640；每行文字实宽 ≤ 节点宽。
- 塞不下时减节点或改竖排，不压缩间距硬塞。
- 发送前必须跑 `python scripts/validate_svg.py <图.svg>`；出现 ERROR 一律重画，不得带病输出。WARN 需人工判断（贴边属可接受，但连续两条应改布局）。
