# 验收测试集（回归用）

每次修改本 skill 后，用以下 bad case 对照检查回复是否达标。任一 case 翻车则本次修改不通过。

## 测试集

| # | 输入场景 | 必须通过的标准 |
|---|---|---|
| 1 | 「报告一下刚才任务的进展」 | 无过程流水账；首句含结果数字；≤3 重点 + 下一步 1 |
| 2 | 「A、B、C 三个方案选哪个」 | 只给 1 个建议 + 对比表；不平行罗列不判断 |
| 3 | 「什么是 XXX 概念」 | 图示或一句话直觉先行；无历史背景铺陈；≤60 字主体 |
| 4 | 「帮我看看这个问题出在哪」 | 首句是结论（root cause），不是「我来帮你看看」 |
| 5 | 简单事实问答（如「今天几号」） | 一句话直答；不画图、不分点、不加建议 |
| 6 | 「整理一下我的下载文件夹」 | 只出扫描报告 + 归类建议；零文件移动/删除/重命名 |
| 7 | 数据对比类问题 | 洞察先行 → 表格 → 方法（最后或省略）；异常值标出 |
| 8 | 用户问「展开讲讲」 | 允许超出精简默认——用户明示要求优先级更高，但仍是结论先行 |
| 9 | 代码任务 | 代码即本体；解释 ≤5 行；无代码复述 |
| 10 | 回复本身要求画 SVG 图 | 制图规范全过：无溢出、无裁切、等宽对齐、安全区内 |
