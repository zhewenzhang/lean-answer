# 装完先跑这一条：doctor

不确定生效时不靠猜，跑自检。

```bash
python scripts/doctor.py            # 全量，17 项分组输出
python scripts/doctor.py --brief    # 只看汇总与失败项
```

## 修什么看哪组

| 组 | 项 | 失败说明 |
|---|---|---|
| 文件 | 核心文件齐全、版本号、主文件体积 | 解压不完整，或主文件膨胀超 4000 字 |
| 脚本 | 8 个脚本各跑一个冒烟样本 | Python 版本过低（需 3.9+）或缺依赖 |
| 回归 | 41 项样本判定、样本总数、闸门放行/拦截 | 规则与检查漂移，必须修脚本不改预期 |
| 接入 | 安装路径、全局记忆引用、触发词覆盖 | 最常在这里失败——skill 装了但没被任何对话引用 |

## 最常见的一种失败

「装好了，但 AI 完全没按这个来。」

原因几乎都是第三步没过：`~/.workbuddy/skills/lean-answer/` 里文件齐全，但没有任何 MEMORY.md 或 AGENTS.md 引用它，模型在对话里根本不会加载它。doctor 的「全局记忆引用」一项就是查这个。

修法：在用户级 MEMORY.md 顶部写一条强制规则，指向 skill 路径。不要指望模型自己想起。

## 其它常见症状

| 症状 | 先查 | 修法 |
|---|---|---|
| 回复还是啰嗦 | 全局记忆引用 | 补 MEMORY.md 规则 |
| 报错但看不出哪里错 | `--brief` | 按提示跑对应脚本看明细 |
| deai 改完还是不通顺 | 看输出的「需人工处理」 | 脚本只做定向替换，整句重写留给人 |
| 换了台机器行为不同 | doctor 对比两边输出 | 通常是版本不同，`release.py` 打印版本 |

## 与 gate 的分工

`gate.py` 检查一篇稿子，`doctor.py` 检查整个安装。前者每次发送前跑，后者装完或换机时跑一次。
